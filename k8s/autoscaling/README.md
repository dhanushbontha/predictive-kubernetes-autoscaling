# Autoscaling Architecture & Configuration

This directory contains the Kubernetes autoscaling manifests for benchmarking reactive vs. predictive autoscaling strategies on the `workload-service` deployment.

---

## 1. Autoscaling Strategies

| Property | Reactive HPA (`hpa.yaml`) | Predictive KEDA (`keda-scaledobject.yaml`) |
| :--- | :--- | :--- |
| **Autoscaler Engine** | Kubernetes Horizontal Pod Autoscaler v2 | KEDA (Kubernetes Event-driven Autoscaling) v2 |
| **Trigger Metric** | CPU Utilization (`Resource: cpu`) | Predicted Request Rate (`predicted_workload_requests_per_second`) |
| **Metric Source** | Kubernetes Metrics Server | Prometheus (generated by Meta Prophet `forecasting-service`) |
| **Target Threshold** | `50%` average CPU utilization | `30 RPS` per replica target |
| **Min Replicas** | `1` | `1` |
| **Max Replicas** | `5` | `5` |
| **Polling Interval** | Standard Metrics Server (15s) | `5s` |
| **Scale Up Behavior** | Immediate (0s stabilization, max +2 pods/15s) | Immediate (0s stabilization, max +2 pods/15s) |
| **Scale Down Behavior** | 60s stabilization window, -1 pod/30s | 60s stabilization window, -1 pod/30s |

---

## 2. KEDA Setup & Installation

To install KEDA on your Kubernetes / Minikube cluster:

```bash
# Add KEDA Helm chart repository
helm repo add kedacore https://kedacore.github.io/charts
helm repo update

# Install KEDA into the dedicated 'keda' namespace
helm install keda kedacore/keda --namespace keda --create-namespace
```

Verify KEDA operator and metrics adapter pods are running:
```bash
kubectl get pods -n keda
```

---

## 3. Applying Autoscaling Configurations

### Reactive Mode (HPA):
```bash
kubectl apply -f k8s/autoscaling/hpa.yaml -n autoscaling-experiment
```

### Predictive Mode (KEDA):
```bash
kubectl apply -f k8s/autoscaling/keda-scaledobject.yaml -n autoscaling-experiment
```

### Verify Status:
```bash
# Inspect HPA
kubectl get hpa -n autoscaling-experiment

# Inspect KEDA ScaledObject
kubectl get scaledobject -n autoscaling-experiment
kubectl describe scaledobject workload-service-keda -n autoscaling-experiment
```
